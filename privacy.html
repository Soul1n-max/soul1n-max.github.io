2. Какие данные обрабатываются

  • Адрес электронной почты — при регистрации по почте.
  • Пароль — хранится только в виде хеша (необратимого преобразования). Оператор пароль не видит.
  • Telegram ID — числовой идентификатор аккаунта Telegram. Нужен, чтобы связать бота с сайтом.
  • Данные входа через Telegram — имя, имя пользователя (username), ссылка на фото профиля, время входа и подпись Telegram. Передаются серверу бота для проверки подписи входа.
  • Содержимое планера — тексты задач и заметок, категории, даты, время, повтор, отметки о выполнении, названия и цвета проектов, сообщения боту с задачами.
  • Технические данные — IP-адрес, сведения о браузере и устройстве, время запросов. Их автоматически записывают в журналы хостинг сайта, база данных и сервер бота.

Специальные категории персональных данных (здоровье, убеждения и т. п.) и биометрические данные Оператор не запрашивает и не обрабатывает. Не записывайте такие сведения в задачи.

Оператор выполняет с данными следующие действия: сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (предоставление, доступ) обработчикам из раздела 7, блокирование, удаление, уничтожение.

  • Данные аккаунта и содержимое планера хранятся, пока существует аккаунт, или до отзыва согласия.
  • После удаления аккаунта или отзыва согласия данные уничтожаются в срок не более 30 дней, если иное не требуется по закону.
  • Технические журналы (IP-адрес, сведения о браузере, время запросов) хранятся не более 90 дней, после чего удаляются автоматически. Поставщики хостинга могут удалять их раньше — по своим правилам.
  • Отдельные задачи и проекты, удалённые кнопкой корзины, удаляются из базы сразу.

9. Как данные защищены

  • Соединение с сайтом, базой и сервером бота шифруется (HTTPS).
  • Правила доступа в базе (Row Level Security) отдают каждую задачу и проект только аккаунту с тем же Telegram ID: другие пользователи их не видят.
  • Пароли хранятся только в виде хеша. Вход через Telegram проверяется по подписи Telegram.
  • Секретные ключи базы и бота не размещаются в коде сайта и доступны только Оператору.
  • Политика безопасности содержимого (CSP) запрещает загрузку скриптов с посторонних адресов.
  • Обрабатывается только тот минимум данных, без которого Сервис не работает.

О случаях неправомерной передачи (утечки) персональных данных Оператор уведомляет Роскомнадзор и пользователей в сроки, установленные законом.
