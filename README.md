# Синергия PM — планнер задач

Веб-планнер задач, календаря и проектов с синхронизацией через Supabase и Telegram-ботом.
Один файл `index.html`, без сборки.

## Возможности

- Задачи с типом (Проект, Контакт, Напомнить, Срочно, Личное), датой, **временем**, проектом и повтором
- Группы «Просрочено / Сегодня / Дальше», сортировка по времени
- Календарь месяца с задачами в ячейках и панелью выбранного дня
- Проекты с цветными метками
- Вход и регистрация (Supabase Auth), привязка Telegram ID
- Realtime-обновление, когда бот добавляет задачи
- Светлая и тёмная тема, адаптивная вёрстка под телефон

## Запуск

Откройте `index.html` в браузере — больше ничего не нужно.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New**).
2. **Add file → Upload files**, перетащите `index.html`, `README.md`, `CLAUDE.md`, нажмите **Commit changes**.
3. **Settings → Pages → Branch: main / root → Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Supabase

В коде используется публичный (publishable) ключ — его можно держать во фронтенде,
но в таблице `tasks` должна быть включена Row Level Security, иначе данные
доступны любому, у кого есть ссылка на сайт.
